# VectorIQ

VectorIQ is a modern web application built using Next.js. This project provides a robust framework for advanced querying and intelligent data interaction.

## Features

* Built with **Next.js** for fast performance and server-side rendering.
* Styled with **Tailwind CSS** for a responsive and clean user interface.
* Scalable project structure with modular components and utilities.
